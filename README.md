# Data Science Salary Analysis

This project focuses on exploring and analyzing a global data science salaries dataset using Python and exploratory data analysis (EDA) techniques.


##Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
  

##Analysis Performed

-Data loading and structure inspection (df.shape, df.info()) 

-Separation of numerical and categorical columns 

-Missing value verification (df.isnull().sum()) 

-Duplicate detection and removal (1,171 duplicate rows dropped)

-Summary statistics including mean, median, mode, and standard deviation for salaries 

-Frequency analysis across job titles, experience levels, and work years 

-Data visualization:

      -Pie chart for the distribution of top 10 job titles 
      -Subplot histograms for numeric features (work_year, salary, salary_in_usd, remote_ratio)
      -Horizontal bar chart of the most common data science roles     
      -Line plot tracking average salary in USD over the years (2020–2023)  

      
##Dataset

The dataset (ds_salaries.csv) includes compensation and employment details across the data science domain, such as job title, experience level, employment type, salary in local currency and USD, company location, employee residence, company size, and remote work ratio.   


##Project Objective

The objective of this project is to analyze compensation trends in data science, examine the distribution of top roles and experience levels, and understand how average salaries have evolved across recent years.
